Авто-заполнение графика

Цикл День → Ночь → Отсыпной → Выходной в выбранном периоде. Линия со своей очередью или закреплёнными сменами продолжает их, остальные идут по умолчанию. Закреплённые смены не меняются.

Пустая дата «по» — до конца месяца. Смены после неё не меняются.
