# Планировщик бригад: руководство пользователя

Приложение помогает составить график работы бригад на линиях фасовки на месяц и указать, кто из сотрудников
работает в каждой смене.

> Надписи в интерфейсе пока на английском. В руководстве они даны в кавычках, например кнопка «New empty month».

## Основные понятия

| Понятие | Что это |
| --- | --- |
| **Линия** | Производственная линия. На линии каждый день две смены. |
| **Смена** | Дневная **08:00–20:00** или ночная **20:00–08:00** (ночная смена относится к дню, в который она начинается). |
| **Бригада** | Группа сотрудников. Для бригады задан состав: какие роли нужны и сколько человек на каждую роль. |
| **Смена бригады** | Одна бригада на одной линии в одну смену одного дня. На одну смену линии — одна бригада. |
| **Состав бригады по умолчанию** | Сотрудники бригады из списка бригад внизу страницы. Действует для всех её смен. |
| **Изменения смены** | Отличия одной смены от состава по умолчанию: кто не работает (отсутствует) и кто работает дополнительно (замена из другой бригады). Касаются только этой смены. |
| **Закреплённая смена** | Смену нельзя перенести или удалить, пока её не открепить. |

Обычный цикл бригады: **День → Ночь → Отсыпной → Выходной** (4 дня), поэтому на линию нужно 4 бригады.

## Экран

Сверху вниз:

1. **Месяц и кнопки**: поле месяца, «New empty month» (новый пустой месяц), «Refresh» (обновить).
2. **Вкладки**: «By line» (по линиям) и «By employee» (по сотрудникам).
3. **Список бригад** («Crews»): состав каждой бригады по умолчанию.

При открытии показывается текущий месяц с сегодняшнего дня (или с 1-го числа, если выбран другой месяц), одна неделя.
Остальные дни — прокруткой; масштаб меняется колёсиком мыши.

## Как составить график на месяц

1. Выберите месяц в поле месяца и нажмите **«New empty month»**. Появится пустой график.
   Внимание: ваш текущий график будет заменён.
2. Проверьте **список бригад** внизу: сотрудники и их бригады (см. «Перевести сотрудника в другую бригаду»).
3. На вкладке **«By line»** расставьте бригады по сменам (см. ниже).
4. Если в какую-то смену состав отличается (болезнь, замена), измените людей **только этой смены**.
5. Закрепите готовые смены значком замка.

## Вкладка «By line» (по линиям)

Строка — линия, прямоугольник — смена бригады. Цвет прямоугольника — цвет бригады.
На прямоугольнике: значок замка, название бригады, время смены и число людей, например
`08:00 - 20:00, 7 people (−1, +1)` — 7 человек, один отсутствует, один на замене.

| Действие | Как сделать |
| --- | --- |
| Поставить бригаду на смену | Двойной щелчок по пустому месту в строке линии (08:00–20:00 — дневная смена, 20:00–08:00 — ночная), выбрать бригаду, «Save». |
| Поменять бригаду в смене | Двойной щелчок по смене, выбрать другую бригаду, «Save». |
| Перенести смену | Перетащить мышью. Смена притягивается к 08:00 или 20:00. Можно перетащить и на другую линию. |
| Удалить смену | Щёлкнуть по смене (выделить) и нажать **×**. |
| Закрепить / открепить | Щелчок по значку замка. Закреплённая смена с толстой рамкой, её нельзя перенести или удалить. |
| Посмотреть и изменить людей этой смены | Щелчок по названию бригады или по надписи с числом людей (значок людей). |

Бригаду, которая уже работает в это время на другой линии, выбрать нельзя: она показана в списке как недоступная.

### Люди одной смены (окно смены)

Окно открывается щелчком по названию бригады на смене. В нём:

- дата, смена, линия и бригада;
- таблица людей смены: ФИО, роли и статус:
  - **crew** — сотрудник бригады (по умолчанию);
  - **substitute** — замена из другой бригады (в скобках — его бригада);
  - **absent** — сотрудник бригады, который в эту смену не работает (зачёркнут);
- кнопки в строке:
  - **«Take off»** — снять сотрудника с этой смены (он станет «absent»);
  - **«Replace by...»** — выбрать, кто выйдет вместо него;
  - **«Works again»** — отсутствующий сотрудник снова работает в эту смену;
- внизу **«Add an employee to this shift»** — добавить свободного сотрудника в эту смену;
- кнопка **«Show the crew in the crew list»** — открыть бригаду в списке бригад внизу.

Изменения в этом окне касаются **только этой смены**. Состав бригады в другие дни не меняется.
В списках для замены и добавления только свободные сотрудники — те, кто в это время не работает ни на одной линии.

Пример: сотрудник заболел 5-го числа. Откройте окно смены его бригады за 5-е число и нажмите «Take off»
или выберите замену в «Replace by...». Если он болеет несколько дней, это нужно сделать в каждой его смене
(ввод больничного на период пока не сделан).

## Вкладка «By employee» (по сотрудникам)

Сотрудники сгруппированы по бригадам. В подписи строки: ФИО, роли, число смен и часов за месяц.
Прямоугольник — смена, в которую сотрудник работает (с линией и бригадой):

- обычный — смена своей бригады;
- **пунктирная рамка** — сотрудник на замене в другой бригаде;
- **серый, зачёркнутый** — смена его бригады, в которую он не работает.

| Действие | Как сделать |
| --- | --- |
| Снять со смены или заменить | Двойной щелчок по смене сотрудника: «Replaced by» — выбрать замену или «Nobody» (на одного меньше). |
| Вернуть на смену | Двойной щелчок по серой смене, «Works this shift again». |
| Добавить в смену | Двойной щелчок по пустому месту в строке сотрудника, выбрать смену бригады в это время, «Add». |
| Открыть бригаду в списке | Щелчок по смене. |

Добавить можно только туда, где в это время уже стоит бригада (сначала поставьте бригаду на вкладке «By line»).

## Список бригад («Crews»)

Щелчок по бригаде раскрывает её:

- **«People per shift»** — роли и число человек на каждую роль в смене (только просмотр, из базы данных);
- **«Employees»** — сотрудники бригады: табельный номер, ФИО, роли и бригада.

### Перевести сотрудника в другую бригаду

Выберите бригаду в колонке «Crew» у сотрудника. Это меняет состав по умолчанию, то есть **все дни месяца**
обеих бригад. Если нужно поменять человека только в одну смену, используйте окно смены (см. выше).

## Ваша версия графика

- У каждой вкладки браузера своя версия графика. Ваши изменения не видны другим пользователям, а их — вам.
  Номер сессии и версии показан под описанием вверху страницы.
- Новая вкладка браузера получает копию графика по умолчанию (текущий месяц, без смен).
- **Изменения хранятся только в памяти сервера.** Они пропадают после перезапуска сервера и после 24 часов
  без работы с версией. Сохранение в базу данных будет сделано позже.
- «Refresh» заново загружает вашу версию с сервера.

## Сообщения об ошибках

Ошибки показываются красным окном вверху страницы. Частые причины:

| Сообщение (смысл) | Что делать |
| --- | --- |
| На линии в эту смену уже есть бригада | Поменяйте бригаду двойным щелчком по существующей смене. |
| Бригада уже работает на другой линии в это время | Выберите другую бригаду или уберите её с другой линии. |
| Сотрудник уже работает в это время | Выберите другого сотрудника или сначала снимите его с другой смены. |
| Смена закреплена | Открепите её значком замка. |
| Дата не в месяце графика | Создайте график нужного месяца кнопкой «New empty month». |
| Нет версии графика | Нажмите «New empty month». |

## Что пока не сделано

- Сохранение графика в базу данных.
- Ввод отпусков и больничных на период.
- Перевод сотрудника в другую бригаду или увольнение с определённой даты (сейчас перевод действует на весь месяц).
- Изменение числа людей бригады на один день.
- Автоматическая расстановка сотрудников по ролям и выгрузка в «Табельный учёт».
