# Планировщик бригад: руководство пользователя

Приложение помогает составить график работы бригад на линиях фасовки на месяц и указать, кто из сотрудников
работает в каждой смене.

## Основные понятия

| Понятие | Что это |
| --- | --- |
| **Линия** | Производственная линия (например «Линия 1», код БерЦГС1). На линии каждый день две смены. Показываются линии, которые действуют в выбранном месяце. |
| **Смена** | Дневная (Д) или ночная (Н). Время смен берётся из базы данных (сейчас **08:00–20:00** и **20:00–08:00**). Ночная смена относится к дню, в который она начинается. |
| **Бригада** | Группа сотрудников. У бригады есть своя линия и число людей, которое нужно в смену. |
| **Смена бригады** | Одна бригада на одной линии в одну смену одного дня. На одну смену линии — одна бригада. |
| **Состав бригады по умолчанию** | Сотрудники бригады на месяц. Действует для всех её смен. |
| **Изменения смены** | Отличия одной смены от состава по умолчанию: кто не работает (снят со смены) и кто работает дополнительно (замена из другой бригады). Касаются только этой смены. |
| **Закреплённая смена** | Смену нельзя перенести, удалить или отдать другой бригаде, пока её не открепить. |
| **Дефицит** | В смене работает меньше людей, чем нужно бригаде. |

Обычный цикл бригады: **День → Ночь → Отсыпной → Выходной** (4 дня), поэтому на линию нужно 4 бригады.

## Экран

Сверху вниз:

1. **Заголовок «График бригад»** и две плашки:
   - «N нарушений отдыха» — сколько предупреждений об отдыхе (см. ниже);
   - «N смен с дефицитом» — в скольких сменах людей меньше, чем нужно.

   Щелчок по плашке прокручивает график к первой такой смене и подсвечивает её.
2. **Панель кнопок**:
   - переключатель месяца ‹ Ноябрь 2026 › — открывает окно нового месяца для предыдущего или следующего месяца;
   - вид **«По линиям»** / **«По сотрудникам»**;
   - ⟳ — заново загрузить график с сервера;
   - **«Новый пустой месяц»**, **«Авто-заполнение»**;
   - **«Сохранить»** пока неактивна: сохранение в базу данных ещё не сделано.
3. **Обозначения**: Д и Н с временем смен, О — отсыпной, В — выходной, Б — больничный, ОТ — отпуск,
   У — увольнение, ПР — другое отсутствие.
4. **График** (по линиям или по сотрудникам). Справа открывается **панель подробностей** смены или сотрудника; график
   при этом остаётся на экране. Панель закрывается крестиком.
5. Внизу — итоги месяца: линий в версии, смен бригад, смен с дефицитом, нарушений отдыха.

## Как составить график на месяц

1. Нажмите **«Новый пустой месяц»** (или стрелку месяца), выберите месяц. Отметьте **«Сгенерировать график»**, чтобы
   сразу заполнить его по циклу, или оставьте флажок пустым — график будет пустым. Нажмите **«Начать месяц»**.
   Внимание: ваш текущий график будет заменён.
2. Расставьте бригады по сменам вручную или кнопкой **«Авто-заполнение»**.
3. Если в какую-то смену состав отличается (болезнь, замена), измените людей **только этой смены**.
4. Закрепите готовые смены (кнопка «Закрепить» в панели смены).

## Авто-заполнение

Генератор расставляет бригады по циклу **День → Ночь → Отсыпной → Выходной** до конца месяца. Для этого у линии
должно быть ровно 4 бригады (линия бригады задана в базе данных). Например, если в первый день днём работает
Линия1/1, а ночью Линия1/2:

| День | 1-й | 2-й | 3-й | 4-й | 5-й |
| --- | --- | --- | --- | --- | --- |
| Дневная смена | Линия1/1 | Линия1/3 | Линия1/4 | Линия1/2 | Линия1/1 |
| Ночная смена | Линия1/2 | Линия1/1 | Линия1/3 | Линия1/4 | Линия1/2 |

В окне «Авто-заполнение»:

- **Линия** — все линии или одна;
- **С даты** — по умолчанию с 1-го числа;
- **Бригада в дневную смену первого дня** — можно выбрать только для одной линии. «Авто» — продолжить смены, которые
  уже стоят до этой даты (если их нет — начинает первая бригада линии);
- **Перезаписать** — сначала удалить смены линии с этой даты (кроме закреплённых). Без флажка заполняются только
  пустые смены, уже поставленные бригады остаются.

После заполнения справа вверху показывается, сколько смен создано и сколько оставлено как было, и сообщения:
линия пропущена (у неё не 4 бригады) или смена оставлена пустой (бригада в это время работает на другой линии).

Закреплённые смены генератор никогда не меняет. Если смены до выбранной даты не подходят под один цикл (например,
их меняли вручную), генератор ничего не делает и просит выбрать бригаду, которая начинает.

Пример: с 15-го числа нужно сдвинуть цикл. Выберите линию, дату 15-го, бригаду, которая в этот день работает днём,
отметьте «Перезаписать» и нажмите «Заполнить».

## Вид «По линиям»

Строка — линия (название и код), столбец — день месяца. Столбец линий и шапка с датами не прокручиваются.
Сегодняшний день подсвечен. В шапке дня: «люди всех смен дня / нужно».

В каждой клетке две карточки: дневная (зелёная) и ночная (сиреневая). На карточке — бригада, начало смены и
«люди / нужно».

| Вид карточки | Что значит |
| --- | --- |
| Розовая, число людей красным | Дефицит: людей меньше, чем нужно |
| Оранжевая рамка | Нарушение отдыха (подробности — при наведении мыши) |
| Тёмная рамка и замок | Смена закреплена |
| Пунктирная «+ Д» / «+ Н» | В эту смену линии бригады нет |

| Действие | Как сделать |
| --- | --- |
| Поставить бригаду | Щелчок по пустой карточке, выбрать бригаду («Бригады линии» сверху, затем «Другие линии»), «Поставить». Бригаду, которая в это время уже работает, выбрать нельзя. |
| Подробности смены | Щелчок по карточке: справа откроется панель смены. |
| Поменять две бригады местами | Перетащить карточку на карточку той же линии и того же типа смены (дневную на дневную). |
| Перенести смену | Перетащить карточку на пустую карточку (можно на другую линию, день или тип смены). |

Закреплённую карточку перетащить нельзя.

### Панель смены

- Тип смены с временем, дата, линия, бригада.
- Людей «работает / нужно», часы смены, закреплена ли.
- Нарушения отдыха этой смены, если есть.
- **Бригада**: выбрать другую бригаду и нажать «Сменить»; «Закрепить» / «Открепить»; «Удалить смену».
- **Люди смены** — изменения касаются **только этой смены**:
  - у работающего: «Заменить…» — выбрать, кто выйдет вместо него; кнопка со значком человека с минусом — снять со смены;
  - у снятого: «Вернуть»;
  - у отсутствующего (отпуск, больничный, увольнение): «Отсутствия» — открыть панель сотрудника;
  - внизу «Добавить сотрудника в эту смену».

  В списках только свободные сотрудники — те, кто в это время не работает ни на одной линии и не отсутствует.
  Щелчок по ФИО открывает панель сотрудника.

Пример: сотрудник не вышел 5-го числа. Откройте смену его бригады за 5-е число и снимите его или выберите замену.
Если он болеет несколько дней, лучше ввести больничный на период (панель сотрудника).

## Вид «По сотрудникам»

Строки сгруппированы по бригадам (бригада, её линия, число сотрудников); внутри бригады — по порядку в бригаде,
затем по ФИО. В подписи строки: ФИО, табельный номер, число смен и часов за месяц (по времени смен).

| Клетка | Что значит |
| --- | --- |
| Д / Н | Работает в дневную / ночную смену (при наведении — линия и бригада) |
| Д / Н с пунктирной рамкой | Работает на замене в другой бригаде |
| Д / Н зачёркнуто | Снят с этой смены своей бригады |
| Б, ОТ, У, ПР | Больничный, отпуск, увольнение, другое отсутствие |
| О | Отсыпной: накануне работал в ночную смену |
| В | Выходной |
| Оранжевая точка | Нарушение отдыха в этой смене |

| Действие | Как сделать |
| --- | --- |
| Снять со смены или заменить | Щелчок по Д / Н: «Кто выйдет вместо него» — выбрать замену или «Никто». |
| Вернуть на смену | Щелчок по зачёркнутой Д / Н, «Вернуть в смену». |
| Добавить в смену | Щелчок по О / В, выбрать смену бригады в этот день, «Добавить». |
| Отпуск, больничный, перевод | Щелчок по ФИО или по клетке отсутствия: панель сотрудника. |

Добавить можно только туда, где в этот день уже стоит бригада.

### Панель сотрудника

- Смены и часы за месяц (сколько дневных и ночных), число нарушений отдыха и их список.
- **Бригада**: бригада на начало месяца и переводы («Отменить» отменяет перевод). Перевод: выберите бригаду и дату
  «с даты», нажмите «Перевести». Без даты — на весь месяц (более поздние переводы удаляются). С даты перевода
  сотрудник работает в сменах новой бригады, до неё — в сменах старой; это действует и на смены, добавленные позже.
- **Отсутствия**: тип (больничный, отпуск, увольнение, другое), первый день «с» и последний «по (включительно)»,
  «Добавить». Сотрудник не работает ни в одну смену, которая **начинается** в эти дни (ночная смена накануне первого
  дня ещё рабочая). У увольнения нет последнего дня. Отсутствия одного сотрудника не могут пересекаться.
  «Удалить» удаляет отсутствие.

## Предупреждения об отдыхе

Между концом одной смены и началом следующей у бригады и у каждого сотрудника должно быть не меньше 12 часов
(число задаётся в настройках сервера). Это только предупреждение: график можно оставить и так.

- Смена, перед которой отдых короче: оранжевая рамка (по линиям) или оранжевая точка (по сотрудникам); при
  наведении мыши видно, с какой сменой и сколько часов отдыха.
- Плашка «N нарушений отдыха» вверху ведёт к первому нарушению.
- Проверяются бригады (смены на всех линиях) и сотрудники (в том числе на замене в другой бригаде; дни отпуска
  и больничного не считаются).

Например, бригада работает днём и в ту же ночь, или ночью и на следующее утро. День, а на следующий день снова
день — это 12 часов отдыха, предупреждения нет. Смены в конце прошлого месяца пока не учитываются.

## Ваша версия графика

- У каждой вкладки браузера своя версия графика. Ваши изменения не видны другим пользователям, а их — вам.
  Номер сессии и версии показан внизу страницы.
- Новая вкладка браузера получает копию графика по умолчанию (текущий месяц, без смен).
- **Изменения хранятся только в памяти сервера.** Они пропадают после перезапуска сервера и после 24 часов
  без работы с версией. Сохранение в базу данных будет сделано позже.

## Сообщения об ошибках

Ошибки показываются окном справа вверху. Текст причины от сервера пока на английском. Частые причины:

| Сообщение (смысл) | Что делать |
| --- | --- |
| На линии в эту смену уже есть бригада (already has crew) | Откройте смену и смените бригаду. |
| Бригада уже работает на другой линии в это время | Выберите другую бригаду или уберите её с другой линии. |
| Сотрудник уже работает в это время | Выберите другого сотрудника или сначала снимите его с другой смены. |
| Смена закреплена (is pinned) | Откройте смену и нажмите «Открепить». |
| Сотрудник отсутствует (VACATION, SICK_LEAVE...) | Выберите другого сотрудника или удалите отсутствие в панели сотрудника. |
| Отсутствие пересекается с другим | Измените даты или удалите старое отсутствие. |
| Дата не в месяце графика | Создайте график нужного месяца. |
| Смены бригад линии не подходят под один цикл | В «Авто-заполнении» выберите линию и бригаду, которая начинает. |
| Нет версии графика | Нажмите «Новый пустой месяц». |

## Что пока не сделано

- Сохранение графика в базу данных (кнопка «Сохранить» неактивна).
- Загрузка отпусков и больничных из табеля (сейчас их вводят вручную, и они хранятся только в версии).
- Продолжение графика с прошлого месяца и проверка отдыха на границе месяцев.
- Часы сотрудников по линиям и выгрузка в «Табельный учёт».
